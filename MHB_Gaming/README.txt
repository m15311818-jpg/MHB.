# MHB Gaming — ملفات البداية

هذه نسخة تأسيسية قابلة للنشر على استضافة مواقع ثابتة، وتتضمن:
- `index.html`: واجهة العميل.
- `admin.html`: لوحة الأدمن.
- `schema.sql`: جداول وصلاحيات قاعدة البيانات.

## مهم قبل النشر
هذه النسخة تستخدم نقاطاً افتراضية فقط، ولا تحتوي على دفع أموال أو مراهنات أو صرف جوائز.
كما أنها ليست لعبة دومينو/كوتشينة مكتملة بعد؛ الموجود حالياً هو التسجيل والموافقة وطلبات المباريات. يجب إضافة قواعد اللعب الفعلية واختبارها قبل إطلاق عام.

## 1) إعداد قاعدة البيانات المجانية
1. افتح https://supabase.com وأنشئ مشروعاً.
2. من Authentication > Sign In / Providers فعّل Anonymous Sign-Ins للاعبين.
3. من SQL Editor الصق محتويات `schema.sql` ثم اضغط Run.
4. من Project Settings > API انسخ Project URL و anon/public key.
5. افتح `index.html` و`admin.html` واستبدل:
   - `PASTE_YOUR_SUPABASE_PROJECT_URL`
   - `PASTE_YOUR_SUPABASE_ANON_KEY`
   بالقيم التي نسختها.

## 2) إنشاء حساب الأدمن
1. من Supabase > Authentication > Users أنشئ مستخدماً ببريد وكلمة مرور.
2. انسخ UUID الخاص به.
3. في SQL Editor نفّذ (استبدل UUID):
   `insert into public.admin_users(user_id) values ('YOUR-ADMIN-USER-UUID');`
4. افتح رابط `admin.html` وسجل الدخول بالبريد وكلمة المرور.

## 3) نشر رابطين دائمين مجاناً
استخدم https://www.netlify.com/:
1. فك ضغط الملف المضغوط.
2. ارفع مجلد `MHB_Gaming` إلى Netlify Drop أو أنشئ موقعاً وارفع الملفات.
3. سيعطيك Netlify رابطاً دائماً للموقع، ويمكنك اختيار اسم متاح من Site settings > Domain management.
4. رابط العميل يكون `https://اسم-موقعك.netlify.app/`
5. رابط الأدمن يكون `https://اسم-موقعك.netlify.app/admin.html`
   (يمكن لاحقاً ربط دومين خاص مدفوع).

## ملاحظات أمنية
- لا تضع `service_role` key داخل ملفات HTML أبداً؛ استخدم anon/public key فقط.
- لا تشارك رابط لوحة الأدمن علناً، واستخدم كلمة مرور قوية وحساب أدمن منفصلاً.
- هذه نسخة MVP تعليمية. قبل استقبال بيانات حقيقية، أضف سياسة خصوصية، تحققاً من أرقام الهاتف، حماية إساءة الاستخدام، وسجلات تدقيق.
- لا تستخدم بيانات شخصية حقيقية أثناء الاختبار.
- الخطة المجانية لها حدود استخدام وقد تتغير، ولا تعني ضمان بقاء الخدمة مجانية أو دون توقف إلى الأبد.
